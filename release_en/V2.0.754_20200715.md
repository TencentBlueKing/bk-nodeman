### [V2.0.754] Release Notes

- Support AIX7 plugin features

- Added MD5 verification during pagent installation to fix Job platform execution failures under concurrency
- Fixed Windows uninstall hanging issue

- Use /proc/net/tcp to detect connections
- Frontend refactored to TypeScript
- Fixed incomplete display of business search box

- Improved reminder when network policies are unreachable
- Prompt for password input when uninstalling AGENT
